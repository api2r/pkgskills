# Install the conditions tests template

Install the conditions tests template

## Usage

``` r
.use_conditions_tests(overwrite = FALSE, open = rlang::is_interactive())
```

## Arguments

- overwrite:

  (`logical(1)`) Whether to overwrite existing file(s). Defaults to
  `FALSE`.

- open:

  (`logical(1)`) Whether to open the file after creation.

## Value

The path to the installed test file, invisibly.
