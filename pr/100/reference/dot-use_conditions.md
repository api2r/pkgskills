# Install the conditions template

Install the conditions template

## Usage

``` r
.use_conditions(overwrite = FALSE, open = rlang::is_interactive())
```

## Arguments

- overwrite:

  (`logical(1)`) Whether to overwrite existing file(s). Defaults to
  `FALSE`.

- open:

  (`logical(1)`) Whether to open the file after creation.

## Value

The path to the installed conditions file, invisibly.
